# 仓配履约数据智能问数系统需求说明

## 1. 项目背景

面向第三方仓配服务商的数据分析场景，建设一个智能问数（ChatBI）系统。企业已建成
仓配履约数据仓库，但运营与仓经理普遍不会写 SQL，取数需求需排队提交给数据团队，
一个"上个月华北仓的出库及时率是多少"这类问题往往要等半天。

系统需让用户直接用自然语言提问，自动完成"理解意图 → 找到正确的表与字段 →
对齐指标口径 → 生成可执行 SQL → 返回结果"的全过程，降低取数门槛，同时保证
口径准确、结果可控。

## 2. 项目目标与功能范围

**元数据管理**

- 维护数据仓库的表信息、字段信息（含列角色：主键 / 外键 / 度量 / 维度）与指标定义
- 元数据一部分由数仓自动采集，一部分由人工补充业务口径
- 对字段与指标建立向量索引，对维度取值建立全文索引

**自然语言问数**

- 用户输入自然语言问题，系统自动选表、选字段、对齐指标口径，生成 SQL 并执行
- 支持多轮关键词扩展，提升口语化表达、简称、错别字的召回率
- 支持时间类表述解析（"去年""上季度""近三个月"）

**准确性保障**

- 生成的 SQL 须经过语法与可执行性校验，失败时携带报错信息自动重写
- 严格遵循指标定义中的业务口径、过滤规则与时间口径，不得偏离
- 仅限查询操作，禁止生成写入 / 更新 / 删除类 SQL
- 仅允许使用元数据中真实存在的表与字段，禁止编造

**质量与工程要求**

- 检索质量需可量化：提供离线评测套件，支持多策略消融与显著性检验
- 各模块分层清晰（客户端 / 仓储层 / 服务层 / 智能体节点），便于替换组件
- 敏感配置（数据库密码、API Key）通过环境变量注入，不得硬编码

## 3. 角色说明

### 3.1 主要使用对象

- **运营 / 仓经理**：查询出库量、妥投时效、仓配成本、库存周转等履约指标，无需掌握 SQL
- **数据分析师**：快速验证取数口径，减少重复写 SQL 的时间

### 3.2 协同角色

- **数据工程师**：维护数仓表结构、补充指标口径定义、校验元数据准确性

## 4. 典型业务场景

### 4.1 聚合统计场景

> "去年各仓的出库单量是多少"

系统需识别指标"出库单量"的口径（如 `COUNT(outbound_id)`），按仓库维度分组，
并正确解析时间范围，生成带 JOIN 与 GROUP BY 的聚合 SQL。

### 4.2 对比与排名场景

> "哪家承运商的妥投率最高"

需识别"妥投率最高"对应比例指标的最大化，生成排序或子查询取最大值的 SQL。

### 4.3 维度筛选场景

> "华北仓今年 3 月的出库单量"

用户说的"华北仓"需精确匹配到库中的维度取值 `warehouse_name = '华北1仓'`，
**不能**退化成模糊匹配——这是本系统用全文索引匹配维度取值的原因。

### 4.4 趋势分析场景

> "按月看今年的出库单量变化"

需按时间维度分组排序，生成趋势类 SQL。

### 4.5 复杂指标场景

> "出库及时率是多少"

"出库及时率"不是某个字段，而是"承诺时效内完成出库的单量 / 应出库单量"的派生指标，
必须从指标定义中取出计算逻辑，不能靠字段名猜测。

## 5. 内容要求

元数据知识库中的每条记录建议包含：

**表信息**：表名、业务描述、所属主题域

**字段信息**：字段名、字段描述、数据类型、**列角色**（主键 / 外键 / 度量 / 维度）、
所属表、取值示例

**指标信息**：指标编码、指标名称、业务描述（口径说明）、关联列、别名（便于口语化问法命中）

**维度取值**：维度字段的实际取值集合（用于全文检索精确匹配）

## 6. 数据说明

- **元数据**：由数仓采集 + 人工补充，存储于 MySQL 的 `meta` 库
- **业务数据**：存储于 MySQL 的 `dw` 库（模拟 Hive 场景），采用**出库单星型模型**：
  - 事实表 `fact_outbound`（出库单量、出库货值、出库时效、妥投时长与妥投结果）
  - 维度表 `dim_date` / `dim_warehouse` / `dim_cargo` / `dim_shipper` / `dim_carrier`
- **当前状态**：初始数仓自带的示例出库数据仅覆盖 2025Q1，
  已用 `scripts/gen_dw_data.py` 按统一口径重建为 2024-01-01 ~ 2025-12-31 共 24 个月的
  仓配履约业务数据，以支撑月度趋势 / 季度对比 / 年度同比类问数场景

## 7. 后续扩展方向

- 自建行业数仓，增加更多事实表与维度表，提升评测区分度
- 支持多轮追问与上下文指代消解（"那华东呢"）
- 支持跨指标对比（"出库单量和妥投率的同比分别是多少"）
- `correct_sql` 支持多轮重试并保留中间结果
- 增加慢查询拦截与代价预估，避免生成全表扫描 SQL
- 查询结果自动图表化，按数据特征推荐图表类型
- 增加权限控制，按角色限制可查询的表与字段
